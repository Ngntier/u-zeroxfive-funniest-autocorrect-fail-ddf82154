A one-line autocorrect fail for the [Funniest Autocorrect Fail](https://make.fun/bounty/u-zeroxfive-funniest-autocorrect-fail-ddf82154) bounty on [make.fun](https://make.fun).

The entry is a domestic text message where autocorrect swapped "chicken" for "children": the oven and dinner make the intended word instantly obvious, while the wrong word turns a routine message into a dark second meaning that lands on first read.

## Run it

```sh
python3 main.py
```

This writes the entry line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline. The line is validated against the gate first: 1–199 characters, a single line, non-blank, valid UTF-8.
